# Glossary

| Term | Meaning |
|---|---|
| **DRC** | Design Rule Check. Verifies layout geometry against process-specific physical rules. |
| **LVS** | Layout Versus Schematic. Compares extracted layout connectivity/devices against the intended schematic/netlist. |
| **PEX** | Parasitic Extraction. Builds an electrically richer model containing layout-dependent parasitic R/C and, where enabled, coupling elements. |
| **PVT** | Process, Voltage and Temperature variation. |
| **Monte Carlo** | Statistical simulation used to explore mismatch and/or process variation distributions. |
| **Pre-layout** | Simulation before layout parasitics are included. |
| **Post-layout** | Simulation using an extracted or parasitic-aware implementation model. |
| **Config view** | A hierarchy configuration that controls which implementation view is used for each cell during netlisting/simulation. |
| **Corner** | A deterministic model/condition combination used for robustness verification. |
| **Signoff** | The final evidence-based review before release to fabrication. |
| **Bring-up** | First controlled power-up and validation of packaged silicon/PCB hardware. |
